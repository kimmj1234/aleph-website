# ALEPH — 코리아 AI 아카데미 학원 웹사이트

## 목적
- AI를 처음 배우는 학생·성인에게 **"AI를 배우는 가장 확실한 첫걸음"** 이라는 학원의 메시지를 전달하는 공식 홈페이지
- 학원 소개, 교육 과정, 강사진, 공지사항을 한곳에서 보여주고, 수강생 로그인·회원가입과 무료 상담으로 이어지게 하는 것

## 구상
- **디자인 원칙:** 학원에서 실제로 운영하는 사이트. 학생이 **쉽고 편하게** 쓸 수 있으면서 **예쁘고 깔끔하게**
- **메뉴바 (2차, 처음부터 다시 제작):** 색 비율 그대로 — 흰 바(바탕) · 딥 틸 글씨와 로그인 버튼(메인) · 연두는 선택 표시 밑줄에만(포인트). 화면 맨 위에 붙어 있는 흰 반투명 바, 선택 밑줄이 고른 메뉴로 미끄러져 이동. 모바일은 ☰ 버튼 + 흰 펼침 메뉴(선택 메뉴는 왼쪽 연두 막대)
- **첫 화면(인트로):** 흐린 클로버 들판 사진 위로 `ALEPH` 글자가 흩어졌다가 모여드는 연출 → 클릭하거나 스크롤하면 **로그인 창** → 로그인해야만 메인으로 넘어감
- **메인 (로그인 후):** 참고 이미지(고급 웰니스 리트리트 페이지)의 에디토리얼 스타일. 아이보리·모래색 구역이 번갈아 나오고, 큰 자연 사진, 명조(Noto Serif KR) 제목, 넓은 자간의 작은 영문 라벨, 가는 선 아이콘, 넓은 여백
  - 순서: 한 줄 띠(Learn · Build · Grow) → 메뉴바(화면 위에 붙어 따라옴) → 첫 화면(이름 인사 + 제목) → 특징 4가지 → 공지사항(글+사진) → 교육 과정 6개 → 취업 준비(사진+체크 목록) → 도움말 → 바닥글
  - 메뉴(학생 홈·학습 메뉴·취업 준비·도움말)는 각 구역으로 이동
- **콘셉트:** 숲·잔디·새싹 = 배움의 성장. 차분한 딥 틸로 신뢰감을 주고, 햇빛 받은 연두로 생동감을 더함

### 색상 (확정)
| 역할 | 색 | 비율 | 쓰는 곳 |
|---|---|---|---|
| 바탕 | 화이트 `#FFFFFF` | 60% | 배경 |
| 메인 | 딥 틸 `#004651` | 30% | 글씨, 헤더, 푸터, 주요 버튼 |
| 포인트 | 연두 `#A9B249` | 10% | 버튼 면, 형광펜 밑줄, 배지, 일러스트 |
| 메인 바탕 | 아이보리 `#F3F0E8` · 모래색 `#E7E2D6` | — | 메인 페이지 바탕(흰색 대신), 구역 구분 |
| 메인 본문 | `#44605f` | — | 아이보리 6.0:1, 모래색 5.3:1 |

- 연두는 흰색과 대비가 2.29:1이라 **글씨로 쓰지 않음**. 연두 위 글씨는 딥 틸(4.59:1) 또는 블랙(8.23:1)
- 흰 바탕에 연두 글씨가 꼭 필요하면 `#757B33` (4.5:1)
- 보조 글씨 `--muted #4f6b70` (5.7:1), 입력칸·선택지 테두리 `--line #7b979b` (3.1:1), 딥 틸 버튼 마우스 올림 `--main-dark #00363f`
- CSS 변수: `--white`, `--main`, `--accent`, `--accent-text` (`index.html`의 `:root`)

### 초록색을 고른 이유
초록은 웹 UI에서 **"긍정·진행"을 뜻하는 전 세계 공통 신호**라서, 사용자가 따로 배우지 않아도 의미가 바로 전달돼요.

| 의미 | UI에서 쓰이는 곳 | ALEPH에서 쓰는 곳 |
|---|---|---|
| **성공·완료** | 폼 제출, 결제 성공, 저장 완료 메시지와 체크 표시 (오류를 뜻하는 빨강과 대비) | 회원가입 완료, 상담 신청 완료 안내 |
| **진행·승인** | 신호등 초록불처럼 긍정적인 행동을 이끄는 '동의', '시작하기', '구매하기' 같은 주요 버튼(CTA) | '교육 과정 보기', '무료 상담', '수강 신청' 버튼 |
| **활성·정상 상태** | 프로필 옆 초록 점 = 접속 중, 시스템 정상 가동 | 진행 중인 강의, 수강 중 표시, 모집 중 배지 |

여기에 학원 콘셉트(새싹·잔디 = **배움의 성장**, "AI를 배우는 첫걸음")가 더해져서, 브랜드 의미와 UI 의미가 한 색으로 겹쳐요.

> 단, `#A9B249`는 밝은 연두라서 흰 바탕 위 글씨나 아이콘에는 쓰지 않아요 (대비 2.29:1).
> 버튼은 연두 면 위에 딥 틸 글씨를 쓰고, 흰 바탕에 초록 글씨나 체크 표시가 필요하면 `#757B33`을 써요.

## 서버 설정 (Supabase)
**연결 완료** — 프로젝트 `aleph-website` (`https://btybbtwrhghebzujrckz.supabase.co`, 서울). 1~4번은 끝났고 5번(관리자 계정)만 남았어요.
`index.html`의 `SUPABASE_URL`/`SUPABASE_KEY`를 비우면 서버 없이 **데모 모드**로 동작해요.

1. [supabase.com](https://supabase.com)에서 새 프로젝트 만들기
2. **Authentication → Sign In / Providers → Email** 에서 **Confirm email 끄기** (아이디로 가입하므로 확인 메일을 보내지 않음)
3. **SQL Editor** 에 [`setup.sql`](supabase/setup.sql) → [`002_dashboard.sql`](supabase/002_dashboard.sql) → [`003_teacher.sql`](supabase/003_teacher.sql) 순서로 붙여넣고 **Run** (각각 한 번만)
4. **Settings → API Keys** 에서 **Project URL** 과 **Publishable key**(`sb_publishable_…`)를 복사해 `index.html` 의 `SUPABASE_URL`, `SUPABASE_KEY` 에 넣기
   - Publishable key는 브라우저에 공개돼도 되는 키예요. 무엇을 읽고 쓸 수 있는지는 DB 규칙(RLS)이 막아요.
   - **Secret key(`sb_secret_…`)는 절대 넣지 마세요.**
5. **관리자 만들기** (관리자도 강사 회원가입으로 만들어요)
   1. SQL Editor에서 첫 강사 고유 코드 만들기 (아직 코드를 발급할 관리자가 없어서 첫 코드만 여기서):
      `insert into public.teacher_codes default values returning code;` → 나온 코드를 복사
   2. 사이트에서 **강사 회원가입** + 그 코드로 관리자용 아이디·비밀번호를 정해 가입
   3. SQL Editor에서 실행: `update public.profiles set role = 'admin' where userid = '그 아이디';`
6. 관리자는 **강사 로그인** 탭(아이디·비밀번호 + 첫 코드)으로 로그인 → 메뉴바 **계정 버튼 → 대시보드** → **강사 고유 코드 → 새 코드 발급** → 코드를 강사에게 전달

### 로그인 규칙
| 누가 | 가입 | 로그인 |
|---|---|---|
| 학생 | 학생 회원가입 (1단계 기본 정보 → 2단계 추가 정보) | 학생 로그인 (아이디·비밀번호) |
| 강사 | 강사 회원가입 + 관리자가 발급한 고유 코드 (코드 하나는 한 명만), 추가 정보 단계 없이 바로 가입 | 강사 로그인 (아이디·비밀번호 + 가입에 쓴 고유 코드) |
| 관리자 | 강사 회원가입(첫 코드는 SQL Editor에서 발급) 후 SQL Editor에서 역할 변경 (사이트에서는 관리자 가입 불가) | 강사 로그인 (아이디·비밀번호 + 가입에 쓴 코드) |
