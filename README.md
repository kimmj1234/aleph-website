# ALEPH — 코리아 AI 아카데미 학원 웹사이트

## 목적
- AI를 처음 배우는 학생·성인에게 **"AI를 배우는 가장 확실한 첫걸음"** 이라는 학원의 메시지를 전달하는 공식 홈페이지
- 학원 소개, 교육 과정, 강사진, 공지사항을 한곳에서 보여주고, 수강생 로그인·회원가입과 무료 상담으로 이어지게 하는 것

## 구상
- **첫 화면(인트로):** 흐린 클로버 들판 사진 위로 `ALEPH` 글자가 흩어졌다가 모여드는 연출 → 클릭하거나 스크롤하면 메인으로 넘어감
- **메인:** 한 화면 = 한 영역. 스크롤하면 영역 단위로 딱 맞춰 넘어감 (scroll-snap)
- **콘셉트:** 숲·잔디·새싹 = 배움의 성장. 차분한 딥 틸로 신뢰감을 주고, 햇빛 받은 연두로 생동감을 더함

### 색상 (확정)
| 역할 | 색 | 비율 | 쓰는 곳 |
|---|---|---|---|
| 바탕 | 화이트 `#FFFFFF` | 60% | 배경 |
| 메인 | 딥 틸 `#004651` | 30% | 글씨, 헤더, 푸터, 주요 버튼 |
| 포인트 | 연두 `#A9B249` | 10% | 버튼 면, 형광펜 밑줄, 배지, 일러스트 |

- 연두는 흰색과 대비가 2.29:1이라 **글씨로 쓰지 않음**. 연두 위 글씨는 딥 틸(4.59:1) 또는 블랙(8.23:1)
- 흰 바탕에 연두 글씨가 꼭 필요하면 `#757B33` (4.5:1)
- CSS 변수: `--white`, `--main`, `--accent`, `--accent-text` (`index.html`의 `:root`)

## 계획
1. 영역 1에 메뉴(학원 소개 · 교육 과정 · 강사진 · 공지사항)와 메인 문구를 새 색상으로 다시 디자인
2. 영역 2, 3에 들어갈 내용 정하기 (교육 과정 소개, 수강 후기, 상담 신청 등)
3. 로그인·회원가입 창을 새 디자인에 맞춰 다시 붙이기
4. 모바일·접근성(대비, 키보드 이동) 점검
5. 서버 연결 후 실제 로그인·회원가입 동작

## 실행
빌드 도구 없이 정적 파일만 사용해요.

```bash
python -m http.server 8000
```

→ http://localhost:8000

## 파일 구조
```
index.html          메인 페이지 (HTML·CSS·JS 한 파일)
index.backup.html   초기화 전 시안 (폴더 탭 메뉴, 로그인·회원가입 창)
assets/             배경 사진, 로고 이미지
색상.txt            확정 색상과 대비 메모
```
